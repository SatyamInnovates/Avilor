Avilor

AI-powered personalized coding roadmap for overwhelmed beginners.

🔗 Live: avilor.onrender.com

What it does

Avilor takes a beginner's goal and generates a personalized, phase-by-phase coding roadmap — pointing them to the right resources at each step instead of leaving them lost in a sea of tutorials.

V2 adds micro-checks: a short question after every phase. Get it wrong, and an AI mentor steps in to actually teach you before you can move forward — turning a one-time roadmap into something you come back to.

Tech stack


Backend: FastAPI
Templating: Jinja2
Database: Supabase
AI: Groq
Hosting: Deployed on Render


Status

Actively building. Currently measuring Day-2 retention on the V2 micro-check mechanic before deciding what ships next.
